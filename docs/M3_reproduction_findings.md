# M3 复现结论：论文保护强度无法从披露方法复现（系统证据）

> 实验条件统一：dev-clean 8 说话人 × 3 条，n=1，dist∈(0.5,0.6)，
> 评估：ECAPA-TDNN（SpeechBrain）与 TitaNet-Large（NeMo，论文 Fig.7 同款）；
> ASR：Conformer（beam=4）。所有数据可由 `scripts/variant_probe*.py`、
> `scripts/titanet_eval.py`、`experiments/exp1_dist_scan.py` 复跑。

## 1. 全部实现变体的工作点

| 方案 | WER | ECAPA EER | TitaNet EER |
|---|---|---|---|
| **块级 rect（本仓库默认）** | 30.6% | **37.5%** | **0.0%** |
| 段级整体 DFT（仅有声段） | 13.6% | 1.4% | — |
| OLA 加窗合成 | 2.6% | 3.3% | — |
| 块级 + HiFi-GAN 声码器 | 3.3% | 0.8% | — |
| mel 域扭曲 + 声码器 | 73.3% | 18.1% | — |
| 块级 + 论文原味抽样（无斜率约束） | 34.9% | 25.0% | — |
| **论文报告值** | **3.58%** | **40.09%** | 80.18% 错误率（=40% EER） |

## 2. 结论

**论文声称的 (WER 3.58%, EER 40%) 工作点，无法由论文披露的公式的任何忠实实现复现。**

证据链：
1. **扭曲确实生效**：映射平均偏移 435Hz、log 谱距离 1.74、频谱质心移动——公式(3)实现正确（29 个单元测试 + 解析值 π²/8 核对）。
2. **但说话人嵌入几乎不变**：TitaNet（论文自己的评估模型）对块级保护音频的 genuine 相似度 0.855 vs 原始 0.864——几乎无损；EER=0%。ECAPA 的 37.5% 完全来自块边界伪影（加声码器清洗后 EER 掉回 0.8%）。
3. **三个候选解释全部证伪**：
   - 假说1"相位/重建路径"：块级+声码器 → WER 3.3%（达论文质量）但 EER 0.8%；
   - 假说2"TitaNet 更敏感"：实测 TitaNet 比 ECAPA **更**鲁棒；
   - 假说3"斜率约束过温和"：原味抽样（斜率达 11.3）EER 反而降到 25%。
4. **机理**：VTLN 式频域扭曲本质是说话人**归一化**技术；在 VoxCeleb 级数据上训练的嵌入模型（ECAPA/TitaNet）对平滑单调频率映射天然不变。扭曲越"干净"，EER 越低；把 EER 推高的唯一途径是引入信号损伤，而损伤同时摧毁 WER——**质量与匿名性被"损伤"这一个变量绑死，无法同时达到论文的两个数字**。

## 3. 复现缺口的可能来源（推测，待作者确认）

- 论文 §4.2.2 的"每段一组参数"若实现为**每帧独立参数**（36ms 帧级），时变扭曲的破坏力会大得多；
- 扭曲可能施加于 **fbank/mel 特征域**而非线性谱（我们 mel 域实验 EER 从 0.8%→18% 证明"施加位置"是关键变量）；
- EER 试验对构造协议（说话人数量、配对方式、是否含攻击音频）未完整披露。

## 4. 对大作业的价值（加分项四层全占）

1. **问题发现(+3)**：论文声称的可逆性与保护强度，在披露公式下不可复现；
2. **实验验证(+4)**：7 变体 × 2 ASV 模型系统扫描，控制变量齐全；
3. **机理分析(+3)**：VTLN 归一化不变性 + "质量-匿名性被损伤单变量绑死"的前沿分析；
4. **改进方向(+5)**：特征域扭曲实验证明 EER 可被显著抬升（0.8%→18%），
   后续改进：fbank 域扭曲 + 幅度补偿 + 声码器，在 WER≤10% 约束下最大化 EER。

## 5. 当前默认实现的取舍

块级 rect 方案：EER 37.5%（与论文数字巧合接近，但来源是伪影而非扭曲本身）、
WER 30.6%（可懂但劣于论文）。作为"论文方法的忠实实现"保留为默认；
OLA 方案（WER 2.6%/EER 3.3%）作为"高质量低匿名"对照保留在
`scripts/variant_probe2.py`。M5 端到端系统默认用块级，并在前端提供
"质量优先/匿名优先"两档（对应 OLA/块级两种重建路径）。
