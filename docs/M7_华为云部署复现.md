## 4. 公网入口

### 4.1 结论

| 方式 | 可用性 | 说明 |
|---|---|---|
| SSH 本地转发 | ✅ 稳定 | `ssh -N -L 7860:127.0.0.1:7860 ...`，仅本人可用 |
| Pinggy SSH-over-443 | ⚠️ 可用但临时 | 免费 60 分钟、随机 URL；已验证 `load_sample` 成功 |
| ModelArts Jupyter 代理 `/proxy/7860/` | ✅ 需登录 | 非匿名公网 |
| Gradio `share=True` | ❌ | 平台代理对 `frp.gradio.live:7000` 返回 403 |

### 4.2 Gradio share 失败详情

```text
# gradio 4.44 在 aarch64 上找的二进制名
site-packages/gradio/frpc_linux_aarch64_v0.2

# 但 HF CDN 上的实际文件名是 frpc_linux_arm64
# CDN 经平台代理不可达（503/401），手动下载并通过 SSH 流上传后：

$ python -c "import gradio; gradio.blocks.Blocks().launch(share=True)"
...
login to server failed: DialTcpByHttpProxy error, StatusCode [403]
Could not create share link.
```

原因：平台代理只放行 `CONNECT host:443`，`frp.gradio.live:7000` 被策略拒绝。
换镜像/换 Gradio 版本都解决不了，故放弃 share。

### 4.3 Pinggy 方案

平台代理允许 `CONNECT a.pinggy.io:443`。Pinggy 在 443 上跑 SSH，且客户端先发
SSH banner 后服务端回 `SSH-2.0-Pinggy.IO`，可正常握手。云端没有 `nc`/`socat`，
因此写了一个纯 Python 的 CONNECT 转发器 `~/connect_proxy.py`：

```python
import os, socket, sys, threading
host, port = sys.argv[1], int(sys.argv[2])
s = socket.create_connection(("127.0.0.1", 9999), 10)
s.sendall(f"CONNECT {host}:{port} HTTP/1.1\r\nHost: {host}:{port}\r\n\r\n".encode())
buf = b""
while b"\r\n\r\n" not in buf:
    c = s.recv(4096)
    if not c:
        sys.exit(1)
    buf += c
head, rest = buf.split(b"\r\n\r\n", 1)
if b" 200 " not in head.split(b"\r\n", 1)[0]:
    sys.stderr.write(buf.decode(errors="replace"))
    sys.exit(1)

def up():
    try:
        if rest:
            s.sendall(rest)
        while True:
            d = os.read(0, 65536)
            if not d:
                break
            s.sendall(d)
    except OSError:
        pass
    finally:
        try:
            s.shutdown(socket.SHUT_WR)
        except OSError:
            pass

threading.Thread(target=up, daemon=True).start()
try:
    while True:
        d = s.recv(65536)
        if not d:
            break
        os.write(1, d)
except OSError:
    pass
```

启动命令（`~/start_tunnel.sh`）：

```bash
#!/bin/bash
cd /home/ma-user/work
exec sleep infinity | ssh -tt \
  -o ProxyCommand="python /home/ma-user/work/connect_proxy.py %h %p" \
  -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null \
  -o ServerAliveInterval=10 -o ServerAliveCountMax=6 -o TCPKeepAlive=yes \
  -o ConnectTimeout=20 -p 443 -R 0:localhost:7860 a.pinggy.io
```

要点：

- `-tt` 必须有：Pinggy 通过交互 shell 打印公网 URL；
- `sleep infinity |`：保持 stdin 不 EOF，否则隧道数秒后断开；
- `ServerAliveInterval=10`：平台代理会静默切断空闲长连接，第一次尝试 3 分钟即
  `client_loop: send disconnect: Broken pipe`，加保活后稳定；
- 每次重连 URL 都会变，从日志提取：
  ```bash
  sed 's/\r/\n/g' ~/pinggy.log | grep -o 'https://[^ ]*' | tail -3
  ```

实测验证（通过公网 URL）：

```text
GET /            → 200
GET /config      → 200
GET /queue/data  → 200 (SSE)
gradio_client submit(api_name="/load_sample") → 成功返回音频
```

## 5. 踩坑清单（云端特有）

| # | 现象 | 根因 | 处理 |
|---|---|---|---|
| 1 | `module 'torch' has no attribute 'npu'` | torch 不自动 import torch_npu | `src/device.py::register_npu()` |
| 2 | `Expected one of cpu, cuda, ... device type` | 同上 | 同上 |
| 3 | `Default encoder for format mp3 ... disabled` | 系统 ffmpeg 4.2 无 libmp3lame | `imageio-ffmpeg` + `src/ffmpeg_util.py` |
| 4 | transformers 报 `huggingface-hub<1.0 is required` | 装了 gradio 5/6 | 降 `gradio==4.44.1`、锁 `hub==0.29.1` |
| 5 | Gradio 页面 500：`argument of type 'bool' is not iterable` | pydantic 2.11 vs gradio 4.44 | `pydantic==2.9.2` |
| 6 | `ImportError: cannot import name 'DEFAULT_CIPHERS'` | urllib3 2.x vs botocore | `urllib3<2` |
| 7 | `test_pipeline` IndexError（需要 ≥4 条 flac） | 无 LibriSpeech | 上传 1 个 chapter |
| 8 | `scp: path canonicalization failed` | 目标父目录不存在 | 先 `mkdir -p` |
| 9 | 本机 `scp` 看不到 Bash 沙箱里刚写的文件 | 沙箱文件视图隔离 | `cat f | ssh 'cat > f'` |
| 10 | `pkill -f "app.main"` 把当前 SSH shell 也杀了 | 命令行本身含该字符串 | 用 pgrep 取 PID，或用 `[a]pp.main` |
| 11 | Gradio share 403 | 代理拦 7000 端口 | 用 SSH 转发 / Pinggy |
| 12 | 隧道 3 分钟断开 | 代理切空闲连接 | `ServerAliveInterval=10` + `sleep infinity \|` |
