## 2. 论文关键数字速查（报告引用）

- 工作点：dist∈(0.5,0.6)，n∈[1,10]：ASV 错误率 80.18% / ASR 错误率 3.58%（选参实验，TitaNet/SpeechBrain-Transformer）。
- Table 5：LS test-clean EER 1.47→34.50→36.77%，WER 2.46→4.80→18.39%；VCTK 1.46→35.66→37.22 / 6.58→14.81→32.69；Volunteers 2.21→30.29→33.66 / 6.35→10.97→29.99。恢复 EER 7.07 / WER 9.90。
- 攻击：10,000 次 reducing，总体成功率 15.87%（84.13% 反而更远）；SG 比 Overo 低 6.8pp（Fig.10）。
- 数据集：test-clean 40人/2620句；VCTK 109人/8163句；volunteers 18人/1300条/约10min每人/办公室底噪。

## 3. 我们的三处"实现选择 vs 论文"（答辩必考点）

1. **检测-时间戳同源**（CTC 词边界代 MFA）：消除参考文本插值失配（旧 FNR 75% 的根因），代价是词表外新词误命中——由手动标注链（论文设计本意）与虚词过滤消化。
2. **warping 斜率约束 + single 整句映射**：往返质量（恢复 WER 2.23%）与可懂度优于论文，代价 reducing 攻击率升高（42% vs 16%）——把论文的"插值差异"损失反转成了我们可量化的权衡曲线（M2/M3/exp2 证据链）。
3. **CP-ABE → KD-ABE 等价降级**：计划内、功能语义等价（四算法、单调访问结构、密码学级拒绝），差异三条（无短密文/DNF-only/撤销重加密）见 `cp_abe.py` 头注释。
